# 写作与返修 v1

先读取有效版本、人物关注点与取舍、环境条件、未决项和作者锁定项。少量候选应有实质差别，普通可逆选择可自主作出；作者尚未确定的关键输入保持未决。

明确本章改变的关系、认识、局势或情绪；写出能完整阅读的正文。环境经由人物活动体现，情感转变有经历支撑，人物选择可追溯到各自处境。

提交正文、canon/state.json、影响范围和state_notes；来源quote必须匹配提交后的原文。返修只处理有依据的问题，保留未改动的有效记录，检查所有声明受影响的章节。未完成影响检查写入unresolved，不能伪称解决。

## 命名依据（作者 2026-10-16 要求）

所有新名字先有依据再入稿，包括人名、姓氏、别名、称号、地名、机构名及其他专名，不能只处理主角或先随意生成、事后附会。先回读作者已有定名和偏好；已有名字沿用时查命名记录，缺项如实补查，不把这次补写的解释说成最初取名动机。

在作品 `research/naming.md` 中逐名记录：名字及对象/首次使用位置；可回查的来源与位置；为什么选这个名字及音译、音意结合或本地化的取舍；字义/意象和本作赋予的寓意；与人物家庭、代际、身份、地域或机构历史的适配；已核实事实、创作解释和 Unknown；候选、Agent 采用或作者确认状态。只出现姓氏也需记录，不为填写记录虚构全名。普通名字同样交代具体选择理由与寓意，不强塞典故、宿命或人物能力标签。

采用参考作品名字时，回查其词义、文学出处和命名语境；没有直接证据的原作者意图保持 Unknown。原创命名写明本作构思依据，不冒充历史词源或原作典故；解释中新增的家庭往事、世界规则等仍按候选与采用流程处理，不能因命名自动成为 Canon。依据不足的新名暂留候选，可用身份称呼继续独立写作，并在 unresolved 列明缺口。命名说明放在记录和交付说明中，不强行塞入正文对白。

新增或修改名字时，命名记录与正文、人物 name/holder、签名笔迹、谐音及精确引文依赖同步检查，列入 affected_paths。若任务包缺少已知命名记录或所需来源，明确缺口，不能默认已核对。

向作者交付含新名的正文时，附简短命名说明与记录位置，让作者能看到为什么这样取、寓意是什么；不把 Agent 采用写成作者确认，也不要求作者逐个批准普通可逆候选才继续写作。

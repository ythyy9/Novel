# 创作与执行边界

本文件依据用户入库的架构整理，不增加作品设定。原则和限额的变动会使已有任务的控制版本失效，应先处置旧任务，再创建新任务。

- 人物与世界驱动探索；近处具体、远处开放，不强迫每章出现反转或同一种情绪曲线。
- 六类信息分开。原作分析、候选和幕后推演不能自动成为已采用事实。
- 主动研究服务于具体知识缺口；保留来源、适用条件、不确定性，区分外部事实、推断与作品规则。
- 逐章达到阶段性要求再继续。审核包含因果、人物、世界与阅读体验；明确错误和重大未决疑点阻止通过，体验差异不冒充客观分数。
- 正文、状态、影响清单同步返修。审核绑定整个输入版本；版本变化后重新审核。
- 作者决定和读者反馈保留原话。模型任务不能创建或修改作者决定、原始反馈和控制规则。
- 控制器的验证与 Codex 只读沙箱是当前保护方式，尚非同账户恶意进程无法突破的操作系统隔离。
- 只用现有 ChatGPT 登录。每个任务最多 3 次尝试、最多 2 次明确无进展停止；不自动重试、不清零计数、不切 API 或购买额度。

暂无限定首部作品、主角、题材或参考作品。工程样本不属于作者作品或 Canon。

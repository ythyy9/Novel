| 项目与路线图对应 | 已有证据与界限 | 类型、优先级和下一验收条件 |
| --- | --- | --- |

停止范围：真实 Codex 和依赖它的真实模型审核/研究停在同一持久任务；文学/方法效果停在所需作者输入与未同步资料。上述阻塞不使已通过工程失效，也不允许模拟替代真实接入。

本轮完成分页和备份恢复回归后，不为保持忙碌无限添加查询功能。下一必要验证是恢复当前云端真实接入；验收成功后再做已知问题检出/误报和通用研究实际调用。若平台运行目录问题尚未解决，不自动重试，不通过搬运秘密、换付费 API 或新建任务绕开停止。

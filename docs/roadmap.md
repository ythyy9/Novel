# 第一版实施路线

状态：**第一版本地工程实现已落地，作品与长期运行验收待开展**。本文件根据[架构方案](architecture.md)整理建设次序，下面的具体内容保留为验收方向。实际证据见[工程验收记录](validation.md)。

| 阶段 | 当前进展 |
| --- | --- |
| 资料与版本 | 已实现六类知识、精确引用、正文与状态同步校验、不可变快照 |
| 任务与接续 | 已实现SQLite队列、单写入者、累计次数、持久停止、显式恢复及Codex适配 |
| 单章闭环 | 已实现写作、独立审核、定向返修和通过门禁；实际作品作者反馈待开始 |
| 研究与跨章返修 | 已实现live web研究接入、来源/条件/不确定性记录、版本失效与引用完整性检查；语义影响仍需审核与作者检验 |
| 系统改进 | 已实现方法版本携带、案例盲序与分组对照、追加反馈及保留/暂用/回滚记录；尚无真实读者证明的改进结论 |
| 连续章节 | 正式作品尚未选定，待作者给出初始创作输入后推进；工程测试不代替此项 |

## 1. 建立项目资料与版本约定

按需要建立 `policies/`、`books/` 和结构化记录。明确创作原则、锁定项、已有授权、停止条件，以及正式正文、候选版本与审核结论的关系。

产物包括基础人物与世界记录、六类信息状态、来源引用规则和版本标识。首部作品及参考作品尚待确定；不要把示例 `book-001` 或《安珀志》当成已选定作品。

验收应能追溯重要事实到原始依据，并区分“已采用”“人物所知”和“尚未决定”；一次返修后，旧审核结论不能无条件用于新版。

## 2. 建立最小任务协议与可恢复控制

定义研究、写作、审核、返修任务的输入输出：任务编号、输入版本、完成步骤、改动文件、审核状态、未决问题、下一步及累计重试记录。采用适合本地使用的轻量控制方式，SQLite 是候选选型。

先接入 Codex，核实实际登录、权限、计费路径、输出格式和工具行为。其他 Agent 保留适配边界，分别验证后再启用。

验收覆盖中断恢复、过期输入、重复提交、正式版本单写入者，以及跨会话保留的等待决策、额度不足、无进展、工具故障和授权边界状态。文件存在与结果合法性由程序检查，不能依赖执行者宣称完成。

## 3. 完成一章的创作与审核闭环

按恢复状态、推演走向、确定章节意图、正文写作、分层审核、定向返修、阶段性通过和状态更新推进。明确错误、合理性疑点与阅读体验判断分开处置，已确认的原则性错误未解决时不得通过。

验收同时使用完整可读样章和作者反馈。审稿意见应指出位置、依据、影响、可能修改方向及牵连内容；局部难分优劣的问题可记录后继续，重大未决争议由作者决定。审核职责可以先在不同会话中依次执行，不要求多个并发模型。

## 4. 验证自主研究与跨章返修

研究由具体缺口触发，先识别缺失前提，再检索或计算。记录问题、来源、结论、适用范围、未定条件和受影响内容，并明确外部事实、推断与作品规则。

通过一次实际早期事件回改检查正文、人物及世界状态、后续章节和审核记录的一致性。条件不足时保留不确定性，不把定性结论包装成精确证明。

## 5. 建立有对照的系统改进

收集重复问题，提出可检验假设；用已有案例及未用于修改方法的案例比较新旧方法，记录保留、暂用或回滚的依据。主观评价允许“各有优缺点”或“没有明确改善”，可通过隐藏版本标签、交换顺序减少评审偏差。

原始反馈、基准、失败案例和原则保持可追溯。候选工作区与外层控制的保护需要实际验证；未实现权限隔离时仅标为流程约束。当前任务不能自行替换控制程序或降低自己的审核标准。

## 6. 用连续几章验证完整流程

| 验证方向 | 所需证据 |
| --- | --- |
| 创作方向 | 作者对沉浸感、人物区分与情感过程的具体反馈，以及对应修改；之后再引入目标读者校准 |
| 审核有效性 | 测试副本中已知问题的检出与正常写法的误报记录；植入问题测试不替代正常阅读评价 |
| 返修完整性 | 早期事件回改后的受影响清单、状态同步及版本对应复核 |
| 接续可靠性 | 在不同步骤中断后的真实恢复结果，无重复覆盖或将草稿误认为通过版本 |
| 方法改进 | 新旧方法的对照案例、未用于调参的案例、退步记录与保留或回滚理由 |

优先观察同类错误、有效审稿意见、误报、返修引入的问题和作者干预需求。运行次数、字数、Agent 数量及自评分不能单独作为成功证据。

## 实施时再确定的事项

- 首部作品的题材、目标读者、初始人物与世界状态、锁定项，以及可使用的参考材料。
- 任务结果结构、版本存储、队列选型、累计重试上限和有限恢复策略。
- 控制程序与执行者的实际权限隔离方式，以及系统更新的验收与回退机制。
- 原文中 `OpenAI Developers`、`Claude Code` 来源占位对应的准确链接、日期，以及当前客户端能力的实测结果。

这些问题在相关阶段前补齐；不影响当前文档入库完成。第一版暂不建设独立网页、大型向量数据库、多专家并发平台或完整世界模拟器。
